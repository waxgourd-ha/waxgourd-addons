# Changelog

*升级日志*

## 0.2.2.5.2

- First release: the official DeepSeek Harness web UI as a Home Assistant app. It can also
  look things up and make changes in your home — just ask.

  *首个版本：DeepSeek Harness 官方 Web 界面作为 Home Assistant 应用。它还能帮你查家里的状态、
  直接动手改 —— 开口说就行。*

- The panel waits for the engine while it starts up, and reconnects by itself when the
  connection drops — no more manual refresh.

  *引擎启动期间面板会等它，连接断了也会自己恢复 —— 不用手动刷新页面。*
