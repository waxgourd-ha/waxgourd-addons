# OmniBox

一站式影视、直播、资源聚合媒体管理面板的 Home Assistant 加载项，基于上游官方镜像 `lampon/omnibox` 构建。

- 默认 Web 端口：`7023`
- 支持架构：`amd64`、`arrch64`
- 数据目录：Home Assistant 加载项数据目录 `/data`，容器内软链接为 `/app/data`

## 安装

1. 在「设置 → 加载项 → 加载项商店 → ⋮ → 仓库」中填入本仓库地址；
2. 刷新后在列表中找到 **OmniBox**，点击安装（镜像较大，约 1.3 GB，请耐心等待）；
3. 安装完成后启动加载项；
4. 点击「打开 Web UI」，或直接访问 `http://<HA地址>:7023`。

## 配置

| 配置项 | 类型 | 默认值 | 说明 |
|---|---|---|---|
| `timezone` | str | `Asia/Shanghai` | 容器时区（IANA 名称，如 `Asia/Shanghai`、`Asia/Hong_Kong`），影响日志与媒体时间显示 |

修改配置后需要重启加载项才能生效。

## 使用

启动加载项后，通过 `http://<HA地址>:7023` 访问管理面板，首次进入按需完成初始化配置（媒体源、索引目录等）。

## 数据持久化

加载项把容器内的 `/app/data` 软链接到 Home Assistant 的持久目录 `/data`：

- 首次启动时，镜像内置的默认数据会复制到 `/data`；
- 之后的配置、数据库、缓存等都保存在 `/data`，重启或升级加载项不会丢失；
- 该目录随 Home Assistant 完整备份一起保存，无需额外映射。

> 建议在升级加载项前先创建一次 Home Assistant 备份。

## 支持的架构

仅 `amd64`。如需在 ARM 设备上使用，可自行修改 `Dockerfile` 顶部的 `BUILD_FROM` 指向第三方 ARM 构建的镜像，并在 `config.yaml` 的 `arch` 列表中加入 `aarch64` 后重新构建。

## 故障排除

1. **Web 界面打不开**：确认加载项已启动且日志无报错；确认 `7023` 端口未被其他服务占用。
2. **配置修改不生效**：修改配置项后需要重启加载项。
3. **升级后数据异常**：确认 `/data` 目录未被清理；升级前建议先做一次完整备份。
4. **查看日志**：「设置 → 加载项 → OmniBox → 日志」。
