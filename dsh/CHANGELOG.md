# Changelog

*升级日志*

## 0.2.2.2.1

- Switched away from a page mid-answer? Tap "regenerate" when you come back and the
  finished result is returned immediately instead of running again.

  *答题中途切走页面？回来点「重新生成」会直接拿到已经跑完的结果，不用再等一遍。*

- The agent no longer gets stuck when the model asks you a question.

  *模型中途向你提问时不再卡住。*

- Engine updated to DeepSeek Harness `0.2.2rc2`.

  *引擎升级到 DeepSeek Harness `0.2.2rc2`。*

- Fresh installs no longer pre-fill an API address: `0.2.x` uses an endpoint the engine ships
  itself, and filling in the old OpenAI-compatible URL returns 404/550. Existing installs keep
  their own settings.

  *新安装不再预填接口地址：`0.2.x` 用引擎内置的端点，填旧的 OpenAI 兼容地址会得到 404/550。
  已安装的实例保持原有设置不变。*
